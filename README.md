# BookWorld

BookWorld is a modern and responsive online book gallery designed to showcase a collection of books through an attractive and user-friendly interface. It provides an organized and engaging way to explore and discover books.

## Features

* 📚 Attractive book gallery
* 🖼️ Collection of book images
* 📱 Responsive and user-friendly design
* 🏠 Home page for exploring books
* 📞 Contact page
* 🕒 Hours information page
* 🎨 Clean and modern interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the BookWorld website.
